# GameDemo

An iOS app built with Swift and SpriteKit.

## Requirements

- **Xcode** 15.0 or later
- **iOS** 16.0 or later
- **Swift** 5.9 or later
- A Mac running macOS Ventura (13.0) or later

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/asayiner/GameDemo.git
   cd GameDemo
   ```

2. Open the Xcode project:
   ```bash
   open GameDemo/GameDemo.xcodeproj
   ```

3. Select your target device or simulator in Xcode.

4. Press **⌘ + R** to build and run.
