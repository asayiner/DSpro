# Contributing to GameDemo

Thank you for your interest in contributing! This document outlines the process for contributing to this project.

## Getting Started

1. **Fork** the repository on GitHub.
2. **Clone** your fork locally.
3. **Create a branch** for your change (see branch naming below).
4. **Make your changes**, then commit and push.
5. **Open a Pull Request** against the `main` branch.

## Branch Naming

Use the following format for branch names:

| Type | Pattern | Example |
|------|---------|---------|
| New feature | `feature/<short-description>` | `feature/add-leaderboard` |
| Bug fix | `fix/<short-description>` | `fix/score-display` |
| Documentation | `docs/<short-description>` | `docs/update-readme` |
| Refactor | `refactor/<short-description>` | `refactor/game-scene` |

## Commit Messages

Write clear, concise commit messages in the imperative mood:

- `Add player movement controls`
- `Fix crash on game over screen`
- `Update README with setup instructions`

## Pull Requests

- Keep PRs focused on a single change.
- Fill out the PR template completely.
- Link any related GitHub Issues.
- Make sure the app builds without errors before submitting.

## Reporting Bugs

Use the [Bug Report](.github/ISSUE_TEMPLATE/bug_report.md) issue template.

## Requesting Features

Use the [Feature Request](.github/ISSUE_TEMPLATE/feature_request.md) issue template.
