# Documentation

This folder is for project documentation, screenshots, and design assets.

## Suggested Contents

- `screenshots/` — App screenshots for the README or App Store
- `architecture.md` — High-level overview of how the app is structured
- `design/` — Wireframes, mockups, or design files

## Example: Adding Screenshots

Place screenshots in a `screenshots/` subfolder and reference them in the root README like this:

```markdown
## Screenshots

| Home Screen | Game Screen |
|-------------|-------------|
| ![Home](docs/screenshots/home.png) | ![Game](docs/screenshots/game.png) |
```
